# أذكارك — أذكار الصباح والمساء

موقعٌ بسيط لقراءة **أذكار الصباح والمساء** مكتوبةً كاملةً بالتشكيل من *حصن المسلم*، مع عدّادٍ باللمس لكل ذكر، وعرضِ ذكرٍ واحدٍ في كل شاشة.

## المميزات
- ملف `index.html` واحد مستقل — كل HTML/CSS/JS بداخله، بدون أي مكتبات خارجية.
- يعمل **بدون إنترنت** بالكامل (PWA + Service Worker).
- قابل للتثبيت على الجوال (Manifest + أيقونات).
- عربي، اتجاه RTL، تصميم موبايل أولاً، ودعم الوضع الداكن تلقائياً.
- نصوص الأذكار موجودة داخل الـHTML لأرشفة محركات البحث (SEO)، مع Open Graph وTwitter Card وJSON-LD وsitemap وrobots.

## الملفات
| الملف | الوصف |
|------|-------|
| `index.html` | الموقع كامل (HTML + CSS + JS) |
| `manifest.json` | إعدادات تثبيت التطبيق (PWA) |
| `sw.js` | Service Worker للعمل دون إنترنت |
| `sitemap.xml` / `robots.txt` | ملفات الأرشفة |
| `logo.png` + أيقونات | شعار الموقع والأيقونات |
